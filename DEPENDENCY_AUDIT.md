## Reproduce the source usage inventory

Run from a checkout of the original Bewitchment repository. Commit `842cd977` contains the Fabric sources used for the comparison.

```sh
git grep -n -E '^import (static )?(net\.fabricmc|dev\.onyxstudios\.cca|dev\.emi|vazkii\.patchouli|virtuoel\.pehkui|io\.github\.(ladysnake|apace100)|eu\.midnightdust|squeek\.appleskin|com\.(terraformersmc|jamieswhiteshirt)|me\.lucko)' 842cd977 -- src/main/java
```

## Forge runtime notes

A clean Forge client hit a MidnightLib 1.4.2 configuration-list race during parallel mod construction. Bewitchment now registers its config in Forge's queued common setup. Two packaged clients subsequently completed resource reload and attempted connection with the same MidnightLib version.
